# Scientific reproducibility metadata

Scientific identifiers, models, provenance projections and artifact metadata belong to the domain
application. Existing `sx:` citations remain readable; SwarmX does not reinterpret them or rewrite
stored records. Domain Agents/tools supply scientific checks through ordinary authorized calls. Work retains
opaque identity/revision plus observed execution provenance; external Memory URIs stay unverified. See [domain references](domain-projects.md) for the retained compatibility
boundary and the external ACP integration limit.
