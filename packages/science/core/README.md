# `@swarmx/science`

Local-first scientific domain services. `ScienceCore` owns the Science Journal, projects,
notebooks, experiments, writing, figures, RO-Crate export, provenance, and content-addressed
artifacts. Tool definitions are transport-neutral and are mounted once by desktop
`ProductServices` for Host REST and native Agent carriers.

Science does not own Agent transcripts, A2A Tasks, AG-UI events, or MCP transport.
